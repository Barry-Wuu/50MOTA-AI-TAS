【このソフトウェアについて】

　このソフトウェアは、魔法の塔を3Dにしてしまおう！ という考えからできた、
「魔法の塔 for Windows」の3DVersionです。立体的なマップとモンスターがウリです。

このバージョンの主な変更点は

・シェアウエアから広告付きフリーソフトとした。（使用制限はありません）
・再生モードを付け加えた。
・マウスボタンを削除し画面クリックでの移動を可能にした。

細かな変更については"修正事項.TXT"を見てください。
