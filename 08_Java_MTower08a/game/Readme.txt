[About this software]
 It may seem that the story is usual. 
 Brave man is trying to save princess caught in the tower. 
 But this is not so usual and normal story. Well, this story is even not from this game. 
 Why? 
 Check this while playing.

 "Magic Tower" is something between the Role Playing Game and puzzle. 
 Play this with no hurry, thinking and deciding what would be the best.

 And there is not the random element in this game.   
 You will get the same result anytime, if it does that is same.

【このソフトウェアについて】

魔法の塔に閉じこめられたお姫様を救うという、どこかで聞いたようなストーリーです。
でも、実はストーリーは全然関係ありません（なぜかって？ それはゲームをプレイしてみればわかるよ）。
中身はRPGですが、パズル的な側面も存在します。頭の体操をかねてじっくりと遊んでください。

「魔法の塔 for Windows」のJava版のソフトですが、完全に同じというわけではありません。

【修正事項】
Ver0.8→Ver0.8a
・アイテム選択をキーボードでできるようにした
・オープニング完成
・セーブデータの中にVersion情報を追加、これで前のデータとの互換性がなくなった。m(_ _)m
・イベント実行中マウス、メニュー、キーボードが有効になっていたのを無効にした
・ＢＧＭのバグ修正および設定を変更
・アイテムのツールヒントをステータス行に表示するようにした
・各階でのイベントを見直した
・メッセージを少し修正
・勇者のアニメーションを改良した
・鍵の初期設定アイコン表示がおかしくなっていたのを修正
・祭壇でマウス操作時、マウス範囲設定が違っていたのを修正
・攻撃状態の時は歩くキャラに変更した
・フォーカスが変わったときメッセージが消えてしまうバグ修正
・フォント関連の設定を変えたときメッセージが消えてしまうバグ修正
・メッセージボックスの位置を改良
・ゲームオーバー時の画面を修正
・剣や盾を取ったとき新旧の剣や盾の表示が重なって表示されてしまうのを修正
・ダイアログでのキー入力をできるようにした

【制限事項】
このVersionの制限は以下の通りです。

・ブラウザでのセーブは不可。(ロードは可)、セーブはJava附属のアップレットビュワーでのプレイに限ります。
(なおアップレットビュワーでのセーブの設定の仕方は附属ドキュメントHowtoSave.htmlを読んでください。)

・Towerは20階までのプレイが可能です。

・ブラウザのVersionによっては音楽ファイルはAuファイルのみ再生可能です。
(エクスプローラー5ではWav、Midiは鳴りません。なおBGMのAuファイルはファイルサイズが大きいため附属していません。Ozのホームページにあります。ダウンロードして下さい。)
