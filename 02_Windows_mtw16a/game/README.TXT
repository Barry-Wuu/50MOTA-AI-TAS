【このソフトウェアについて】

魔法の塔に閉じこめられたお姫様を救うという、どこかで聞いたようなストーリーです。
でも、実はストーリーは全然関係ありません（なぜかって？ それはゲームをプレイしてみればわかるよ）。
中身はRPGですが、パズル的な側面も存在します。頭の体操をかねてじっくりと遊んでください。

Ver1.5までで報告されたバグを修正したバージョンです。もちろん完成版です。v(^_^)v
